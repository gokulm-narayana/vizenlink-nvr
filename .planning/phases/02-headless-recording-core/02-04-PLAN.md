<interfaces>
Defines:
- `PathConfiguration`:
  - `name`: `cam/<serial-lowercase>/main` or `sub`
  - `source`: RTSPS URL with credentials and fingerprint
  - `sourceOnDemand`: False for main recorder, True for sub
  - `record`: bool (based on mode, schedule, storage health)
  - `recordFormat`: "fmp4"
  - `recordPartDuration`: "1s"
  - `recordSegmentDuration`: "60s"
  - `recordDeleteAfter`: "0s"
  - `runOnRecordSegmentComplete`: "nvr recording hook-segment-complete"
- `MediaMtxReconciler`:
  - `compute_desired_paths(session, storage_path, volume_ok, now_utc, timezone)` -> dict[str, PathConfiguration]
  - `reconcile(client, api_base, control_auth, desired_paths)` -> ReconcileResult(added, patched, deleted, unchanged)
- CLI subcommand `nvr recording reconcile`
</interfaces>
</context>
