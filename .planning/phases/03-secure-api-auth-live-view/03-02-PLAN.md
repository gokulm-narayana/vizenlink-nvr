2. Implement `src/vizenlink_nvr/api/v1/auth.py` providing endpoints:
   - `GET /status`: returns `{"initialized": bool}`.
   - `POST /setup`: accepts `owner_username`, `owner_password` (min 8 chars), `timezone`, `storage_path`, `allow_system_disk`. Rejects if already initialized. Creates Owner and sets session cookie.
   - `POST /login`: checks rate limiter; validates username and Argon2id hash; on success clears rate limiter and sets HTTP-only `session_id` cookie; on failure records failure in rate limiter.
   - `POST /logout`: deletes session in DB and clears cookie.
   - `GET /me`: returns user profile and permissions.
   - `POST /password`: updates user password.
3. Write `tests/integration/test_auth_setup_wizard.py` testing first-run setup flow, rejecting short passwords (<8 chars), locking out subsequent setup calls once initialized.
4. Write `tests/integration/test_auth_sessions.py` testing login, HTTP-only cookie setting, authenticated endpoint access, and logout session clearing.
5. Write `tests/integration/test_auth_rate_limiting.py` verifying 5 failed login attempts trigger HTTP 429 / lockout.
