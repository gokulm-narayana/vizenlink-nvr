Defines:
- `/api/v1/cameras`:
  - `GET /`: list cameras (filtered by caller permissions for viewers)
  - `GET /{serial}`: camera details, stream profiles, health
  - `POST /`: add new camera (with atomic validation and credentials)
  - `DELETE /{serial}`: remove camera (with `keep_recordings` parameter)
  - `POST /{serial}/reprobe`: trigger live reprobe
- `/api/v1/recording`:
  - `GET /status`: per-camera recording mode, schedule, retention, segment age
  - `PATCH /{serial}`: update mode, schedule, audio_enabled, retention_days, retention_max_gb
- `/api/v1/storage`:
  - `GET /status`: disk usage, free bytes, mountpoint, reserve bytes, retention days estimate
  - `POST /set-path`: update recording storage path
  - `POST /scan`: trigger background disk scan
- `/api/v1/health`:
  - `GET /`: overall recorder health, database/API/MediaMTX statuses, summary counts
- `tools/check_api_breaking_changes.py` detecting breaking changes against `contracts/openapi_v1_baseline.json`.
</interfaces>
