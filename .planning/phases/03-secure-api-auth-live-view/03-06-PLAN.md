   - `record_online`: finds open outage, sets `ended_at = now`, calculates `duration_seconds = (ended_at - started_at).total_seconds()`.
   - `get_outage_history`: queries outages with optional `camera_serial` filter.

   - Evaluates:
     1. Camera offline longer than N minutes (default 5 min).
     2. Disk nearly full (free space < reserve threshold + 1GB hysteresis).
     3. Active recording gap watchdog alarm.
   - Returns structured alert items (`id`, `severity`, `title`, `message`, `timestamp`).
3. Add `GET /api/v1/health/alerts` and `GET /api/v1/health/outages` to `src/vizenlink_nvr/api/v1/health.py`.
