  <files>src/vizenlink_nvr/web/src/services/player.ts, src/vizenlink_nvr/web/src/services/grid_storage.ts, tests/unit/test_tile_state_machine.py, tests/unit/test_layout_persistence.py, tests/integration/test_sub_stream_auto_switch.py</files>
  <action>
1. Implement `src/vizenlink_nvr/web/src/services/player.ts`:
   - `WhepPlayer`: initiates `RTCPeerConnection`, creates SDP offer with `addTransceiver("video", {direction: "recvonly"})`, posts offer to `/cam/{serial}/{stream}/whep?token={token}`, applies SDP answer, binds media stream to `<video>` element.
   - Monitors connection state: on failure or timeout (5s), transitions to `HlsFallbackPlayer`.
   - Truthful state tracker: `connecting` -> `live` -> `offline`/`error`. Watches video element `timeupdate` and `stalled` events. If stream freezes for > 5s, transitions out of `live` state to `connecting` or `offline` with auto-reconnect backoff.
   - Dynamic stream switcher: switches smoothly between `sub` and `main` stream endpoints upon tile maximization.
2. Implement `src/vizenlink_nvr/web/src/services/grid_storage.ts`:
   - Saves and loads grid dimensions (1, 2, 3, 4) and slot-to-camera serial mapping from `localStorage`.
3. Create `tests/unit/test_tile_state_machine.py` verifying state transitions: `connecting` -> `live` -> `stalled/reconnecting` -> `offline`.
4. Create `tests/unit/test_layout_persistence.py` testing serialization and restoration of grid slot configurations.
5. Create `tests/integration/test_sub_stream_auto_switch.py` verifying that grid views request `stream=sub` tokens and maximized views request `stream=main` tokens.
