     - Detects clock offset between camera time in message header/response and NVR UTC clock (`HLTH-09`). If $> 5\text{s}$, flags `clock_sync_state = "uncertain"` and sets `start_time = utc_now()`.

<task type="auto" tdd="true">
  <name>Task 2: Implement EventSubscriptionSupervisor with resilient reconnect backoff</name>
  <files>src/vizenlink_nvr/events/supervisor.py, tests/integration/test_event_subscription_supervisor.py</files>
  <action>
1. Create `src/vizenlink_nvr/events/supervisor.py`:
   - `EventSubscriptionSupervisor`:
     - Discovers active cameras in database.
     - Spawns background worker task per camera running the subscription lifecycle:
       1. Check camera reachability & clock.
       2. Subscribe via `EventSource`.
       3. Poll loop (`poll(timeout_seconds=5)`), yielding events to registered listener.
       4. Auto-renew subscription every 30s.
       5. On network error or SOAP fault, transition state to `reconnecting`, log warning, and back off exponentially (1s, 2s, 4s... max 60s).
     - Updates `event_subscriptions` table (`state`, `last_event_at`, `error_reason`, `updated_at`).
2. Author `tests/integration/test_event_subscription_supervisor.py` testing:
   - Lifecycle: start, event receipt, subscription renewal, error handling, recovery, and clean shutdown.
  </action>

  </verify>
