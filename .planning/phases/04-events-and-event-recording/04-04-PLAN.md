  <name>Task 1: Implement SegmentProtectionService and wire into janitor</name>
  <files>src/vizenlink_nvr/events/protection.py, src/vizenlink_nvr/services/janitor.py</files>
  <action>
1. Create `src/vizenlink_nvr/events/protection.py`:
   - `SegmentProtectionService`:
     - Calculates effective protected window:
       $$W_{start} = \text{event.start\_time} - \text{timedelta(seconds=pre\_roll)}$$
       $$W_{end} = (\text{event.end\_time or event.start\_time}) + \text{timedelta(seconds=post\_roll)}$$
     - Finds all segments in `segments` where `camera_serial == event.camera_serial` and `start_time < W_end` and `end_time > W_start`.
     - Updates them: `is_protected = True`, `protection_reason = f"event:{event.id}"`.
     - Returns count of newly protected segments.
2. In `src/vizenlink_nvr/services/janitor.py`:
   - Verify that all deletion queries (`enforce_retention`, `enforce_disk_low_water_mark`) strictly enforce `Segment.is_protected == False`.
  </action>

  </verify>
  <acceptance_criteria>
    - Overlapping segments are protected across pre-roll and post-roll
    - Janitor never prunes protected segments
  </acceptance_criteria>
