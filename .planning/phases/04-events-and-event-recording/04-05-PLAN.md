  <files>src/vizenlink_nvr/api/v1/events.py, src/vizenlink_nvr/api/app.py</files>
  <action>
1. Create `src/vizenlink_nvr/api/v1/events.py`:
   - `events_router = APIRouter(prefix="/events", tags=["events"])`
   - Define Pydantic models: `EventResponse`, `EventListResponse`, `EventSubscriptionStatusResponse`.
   - `GET /api/v1/events`:
     - Params: `camera_serial`, `event_type`, `start_time`, `end_time`, `is_locked`, `limit`, `offset`.
     - Checks user role. If Viewer, restricts `camera_serial` to `[p.camera_serial for p in user.permissions]`. If requested camera not permitted, return 403 or empty list.
   - `GET /api/v1/events/{id}`: retrieves event by ID, verifies viewer access.
   - `GET /api/v1/events/{id}/snapshot`: returns `FileResponse` for JPEG file with `image/jpeg` content-type.
   - `POST /api/v1/events/{id}/lock` & `POST /api/v1/events/{id}/unlock`:
     - Requires Operator or Owner role.
     - Toggles `is_locked` on event and updates overlapping segment protections.
     - Records audit event `event.lock` / `event.unlock`.
   - `GET /api/v1/events/subscriptions/status`:
     - Returns subscription status per camera (`state`, `last_event_at`, `error_reason`, `clock_sync_state`).
2. In `src/vizenlink_nvr/api/app.py`:
   - Include `events_router` in `v1_router`.
3. Update `contracts/openapi_v1_baseline.json` with `tools/check_api_breaking_changes.py --update`.
