<task type="auto" tdd="true">
  <name>Task 2: Implement MobileAuthService</name>
  <files>src/vizenlink_nvr/services/mobile_auth.py, src/vizenlink_nvr/api/dependencies.py</files>
  <action>
1. Create `src/vizenlink_nvr/services/mobile_auth.py`:
   - Class `MobileAuthService`:
     - `create_qr_pairing_session(db: AsyncSession, user_id: int, ttl_seconds: int = 300) -> tuple[str, str]`:
       Returns `(pairing_code, qr_payload_string)`.
     - `pair_via_qr(db: AsyncSession, pairing_code: str, device_id: str, device_name: str, platform: str) -> dict`:
       Validates pairing code, verifies not claimed or expired, creates `PairedDevice`, generates access/refresh tokens, marks session claimed.
     - `pair_via_credentials(db: AsyncSession, username: str, password: str, device_id: str, device_name: str, platform: str) -> dict`:
       Authenticates via `UserManager.authenticate_user`, creates `PairedDevice`, generates access/refresh tokens.
     - `refresh_token(db: AsyncSession, refresh_token: str) -> dict`:
       Validates refresh token, checks `not is_revoked` and `expires_at > now`, generates new access token and updates last_seen_at.
     - `validate_mobile_token(db: AsyncSession, token: str) -> tuple[PairedDevice, User] | None`:
       Looks up device by access_token, checks `not is_revoked` and `access_token_expires_at > now`, updates sliding last_seen_at, returns device and user.
     - `revoke_device(db: AsyncSession, device_pk: str, revoked_by: User) -> bool`:
       Sets `is_revoked = True`, `revoked_at = utc_now()`, logs to audit log.
     - `list_devices(db: AsyncSession, user_id: int | None = None) -> list[PairedDevice]`:
       Lists paired devices (optionally filtered by user_id for non-admin callers).
2. Update `src/vizenlink_nvr/api/dependencies.py`:
   - In `get_current_user_optional`, if `SessionManager.validate_session` does not match, attempt `MobileAuthService.validate_mobile_token(db, token)`. If valid, return the associated user! This seamlessly allows mobile Bearer tokens on all existing endpoints.
  </action>
