<task type="auto" tdd="true">
  <name>Task 1: Implement mobile API router and integrate into FastAPI app</name>
  <files>src/vizenlink_nvr/api/v1/mobile.py, src/vizenlink_nvr/api/app.py, contracts/openapi.baseline.json</files>
  <action>
1. Create `src/vizenlink_nvr/api/v1/mobile.py`:
   - Pairing routes:
     - `POST /pair`: direct credential pairing.
     - `POST /pair-qr`: QR pairing code claim.
     - `POST /refresh`: access token refresh.
     - `POST /qr/init`: create QR pairing session (requires authenticated user).
     - `GET /devices`: list paired devices (admin or caller's devices).
     - `POST /devices/{device_id}/revoke` (or DELETE): revoke paired device.
   - Live streaming relay route:
     - `GET /cameras/{camera_id}/live-stream`: query param `profile: Literal["main", "sub"] = "sub"`.
       Issues signed media token via `MediaAuthService` and returns WHEP, HLS, and RTSP stream URLs.
   - Recordings routes:
     - `GET /cameras/{camera_id}/recording-dates`: list dates with footage (YYYY-MM-DD).
     - `GET /cameras/{camera_id}/recordings`: query param `date: str`. Returns clip list with timestamps, duration, size, and trigger classification.
   - Status & Health route:
     - `GET /status`: consolidated system health (healthy/degraded), disk stats (total, used, free, retention days), and per-camera online/recording/bitrate/storage stats.
   - Camera management routes:
     - `POST /cameras`: add camera (Requires Owner/Admin).
     - `DELETE /cameras/{camera_id}`: remove camera (Requires Owner/Admin).
     - `PUT /cameras/{camera_id}/recording-mode`: change recording mode (Requires Owner/Operator).
2. Wire router into `src/vizenlink_nvr/api/app.py`:
   - `app.include_router(mobile_router, prefix="/api/v1/mobile", tags=["mobile"])`.
3. Update OpenAPI baseline:
   - `uv run python tools/check_api_breaking_changes.py --update`.
  </action>
