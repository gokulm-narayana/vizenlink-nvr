  <action>
1. Create `src/vizenlink_nvr/services/backup.py`:
   - `create_backup(db_path: Path, output_dir: Path) -> tuple[Path, dict[str, Any]]`:
     - Connects via sqlite3.
     - Executes `VACUUM INTO ?` to output snapshot file.
     - Computes SHA-256 hash.
     - Writes `.meta.json` with timestamp, size, hash, and alembic head revision.
   - `restore_backup(backup_db_path: Path, target_db_path: Path) -> bool`:
     - Validates file exists.
     - Connects and runs `PRAGMA integrity_check`. If not "ok", raises ValueError.
     - Creates atomic rollback backup of target DB (`target_db_path.bak`).
     - Atomically swaps/copies backup file into `target_db_path`.
2. Create `src/vizenlink_nvr/cli/backup_cmd.py`:
   - `nvr backup create [--out path] [--json]`
   - `nvr backup restore --file path [--force]`
3. Mount `backup_app` into `src/vizenlink_nvr/cli/app.py`.
