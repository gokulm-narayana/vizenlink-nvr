API facts: `GET /api/v1/auth/status` returns `{initialized, authenticated, user|null, site_timezone|null}` (`site_timezone` from 09-02); `POST /auth/login {username,password}` returns 401 on bad credentials and 429 on lockout; `POST /auth/setup` takes the six fields and sets the session cookie; `POST /auth/logout`. The cookie is HTTP-only and SameSite=Lax, so the client never sees a token. Import router APIs from `react-router`, and `RouterProvider` from `react-router/dom`.

`src/lib/api.ts`:
- `apiFetch<T>(path, init?)` sends JSON (sets Content-Type when the body is a plain object; serializes it) with same-origin credentials. It returns parsed JSON, or undefined for 204.
- On a non-2xx response it throws `ApiError` with `status` and a `detail` string (FastAPI `detail` string, or the first message of a validation array).
- `setUnauthorizedHandler(fn)`: when a 401 comes from any path other than `/api/v1/auth/status`, `/auth/login`, `/auth/setup` or `/auth/logout`, call the handler before throwing.

`src/lib/queries.ts`:
- `createQueryClient()` with defaults `retry: 1` and `refetchOnWindowFocus: true`.
- An `AuthStatus` type (including `site_timezone: string | null`).
- `useAuthStatus()`, query key `["authStatus"]`, `staleTime: 0`.
- `useCurrentUser()`, which derives `{ id, username, role, permissions }` from auth status.
Later plans add shared hooks to this file.

`src/features/auth/AuthGate.tsx`: a layout route element that reads `useAuthStatus()` and `useLocation()`, applies rows 1 to 6 and 10 with `<Navigate replace>`, and otherwise renders `<Outlet/>`. Build the `next` value as `encodeURIComponent(pathname + search)`.
