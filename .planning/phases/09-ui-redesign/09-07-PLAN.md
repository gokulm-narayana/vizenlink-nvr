## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client role to server authority | Client-side role filtering is cosmetic; the server enforces roles |
| localStorage to UI state | Persisted values may be tampered with or malformed |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-15 | Elevation of privilege | Hidden routes reached by URL | medium | mitigate | `RequireRole` shows the 403 state; every API call stays server-authorized (`require_role`); no client-only permission is trusted |
| T-09-16 | Tampering | Malformed localStorage values | low | mitigate | The store parses with try/catch and falls back to defaults; only the enumerated values are accepted |
| T-09-17 | Information disclosure | Persisted client state | low | accept | Only theme, sidebar, view mode and read-event ids are stored; no secrets or tokens (A17) |
