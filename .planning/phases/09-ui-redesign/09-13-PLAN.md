API facts: `GET /api/v1/gallery?camera_serial&item_type&start_time&end_time&limit&offset` returns `{items[{id,camera_serial,item_type,title,file_path,file_size_bytes,duration_seconds,captured_at,created_at,user_id}], total, limit, offset}`. `GET /gallery/{id}/download` returns the file. `DELETE /gallery/{id}`. There is no server-side user filter.

Planner decision, recorded in the SUMMARY: the Advanced user filter is applied client-side to the loaded items by `user_id`. Options are "Anyone", "Me" (the current user) and, for owners only, each username from `GET /api/v1/users`. The filter applies to loaded pages; "Load more" fetches further pages. No backend change.

Only this plan edits `features/gallery/` and `legacy/GalleryView.tsx`.
