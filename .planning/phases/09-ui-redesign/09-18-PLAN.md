API facts: `GET /api/v1/cameras/{serial}/health` uses `RequireViewer` plus `verify_camera_access`, so a viewer may read health for assigned cameras and gets 403 otherwise. Reboot and factory reset use `RequireOperator`. The factory-reset endpoint requires `confirmation`.

SET-06 wording: REQUIREMENTS.md says "Owner/Admin can factory-reset". The code has roles viewer, operator and owner only (D-10), and Phase 6 shipped the endpoint with `RequireOperator`. The UI-SPEC Cameras table keeps "operator and owner, as implemented". This plan follows the implementation and changes no authorization; record the mapping in the SUMMARY as an owner follow-up (amend the requirement text, or tighten the endpoint in a later phase).

File ownership: this plan edits `features/cameras/` files listed above and creates `features/cameras/health/`. `features/cameras/add/` belongs to 09-20.
