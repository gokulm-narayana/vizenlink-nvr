API facts (all `RequireOwner`):
- `GET /api/v1/users` returns `[{id, username, role, is_active, created_at, updated_at, permissions[]}]`.
- `POST /users {username, password (min 8), role, permissions[]}` returns 201; a duplicate username returns 409; unknown serials return 400.
- `PATCH /users/{id} {role?, is_active?, permissions?}`.
- `POST /users/{id}/reset-password {new_password}`.
- Disabling a user or resetting their password signs them out everywhere. The API rejects an owner disabling or demoting themselves with 400.

Only this plan edits `features/users/`.
</context>
