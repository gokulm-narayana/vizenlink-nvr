# Summary: privacy zone editor - clear save flow and Zone-mode notice

## Root cause of "apply is not working"
The zone was being saved on the camera. The screen just never showed it: the reference picture was not reloaded, the editor jumped back to "New zone" with the same blue box, and zones do nothing while privacy mode is `None` (the default), which the page did not say.

## Changed
- `web/src/features/cameras/PrivacyZones.tsx`
  - Picture reloads after every save, delete and mode change.
  - The saved zone stays selected; Save is disabled until something changes, so a second click cannot create a duplicate.
  - Notice when mode is not `Zone` ("Your zones are saved, but they are not hiding anything yet...") with a "Turn on Zone mode" button behind a one-click confirmation. It sends the existing `setPrivacyMode` action. The mode is read with the same query key as the Privacy tab, so no extra camera request.
  - Zone buttons ("Zone 1", "Zone 2", "Add zone") replace the dropdown; saved zones can also be clicked on the picture.
  - No box is shown until the user draws one; hint "Drag on the picture to draw your first zone".
  - A plain click no longer wipes the selected zone (drags under 2% are ignored).
  - The selected zone is tinted only while it has unsaved changes, so the camera's own black mask is visible once saved.
  - Left/Top/Width/Height moved under "Set exact position".
  - Delete uses a normal confirmation ("Keep zone" / "Delete zone from camera") instead of typing the camera name.
- `services/sim_camera.py`: simulated snapshot draws masks only when privacy mode is `Zone`.
- `web/src/features/cameras/features.test.tsx`: 2 tests updated, 3 added.

## Not changed
- NVR API routes and payloads, `camera/onvif/masks.py`, and everything under `camera_api`. The mask wire format already matches `MaskClient`.

## Verified
- Typecheck clean; Vitest 434 passed; design gates 0 violations; build OK.
- Backend 572 passed, 1 skipped.
- Browser (headless Chromium, simulated camera): draw + save reloads the picture and keeps Zone 1 selected; plain click keeps the zone; "Turn on Zone mode" switches the camera to Zone and the picture shows the black masks; second zone added and deleted; camera ends with `Mask_1` and mode `Zone`.

## Not verified
